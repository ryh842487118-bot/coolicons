# Changelog

## 5.4.1

- Aligns the corner-selection API with the upstream website's `Corners` terminology (`corners` and `CoolIconCorners`).
- Keeps `radius` and `CoolIconRadius` as deprecated compatibility aliases.
- Simplifies the Flutter package documentation for end users.

## 5.4.0

- Adds the community-maintained Flutter adapter and generated icon catalog.
- Supports Flutter 3.41+ and Dart 3.11+.
- Uses Flutter's built-in Material library without a standalone Material UI dependency.
- Aligns the public corner-selection API with the upstream website's `Corners` terminology.

- Initial community-maintained Flutter adapter release.
- Includes the Coolicons 5.4.0 icon artwork and catalog.
- Adds Flutter widgets, global and local theme support, and SVG rendering options.
