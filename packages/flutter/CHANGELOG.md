# Changelog

## 0.1.0

- Initial community-maintained Flutter adapter.
- Add global and local theme configuration.
- Add Line, Duocolor, Duotone, Fill and Bulk style selection.
- Add Sharp, Regular and Round SVG radius selection.
- Add size, primary color, stroke width and secondary-layer controls.
- Add generated Dart icon catalog from the upstream Coolicons SVG source.
